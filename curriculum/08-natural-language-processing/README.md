# 08 — Natural Language Processing

Learn how text is represented, modeled, retrieved, and generated.

## Suggested progression

1. text preprocessing
2. n-grams
3. Bag of Words
4. [TF-IDF](tf-idf/)
5. word embeddings
6. sequence models
7. RNNs and LSTMs
8. attention
9. transformers
10. language modeling
11. fine-tuning
12. retrieval and RAG
13. LLM evaluation

## Available learning units

### [TF-IDF](tf-idf/)

Learn how term frequency and inverse document frequency combine into a sparse text representation, implement the method from scratch, compare it with scikit-learn, and investigate its assumptions and failure modes.
