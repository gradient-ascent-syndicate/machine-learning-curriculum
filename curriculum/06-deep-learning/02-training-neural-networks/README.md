# 02 — Training Neural Networks

This subtrack explains how neural networks learn and why optimization can succeed or fail.

## Learning units

- empirical risk minimization
- backpropagation
- automatic differentiation
- gradient checking
- batch, stochastic, and mini-batch gradient descent
- momentum and Nesterov acceleration
- AdaGrad, RMSProp, Adam, and AdamW
- learning-rate schedules and warm-up
- vanishing and exploding gradients
- Xavier/Glorot and He/Kaiming initialization
- gradient clipping
- batch size and optimization noise
- convergence diagnostics

Learners should implement backpropagation manually at least once before relying entirely on autograd.
