# 06 — Practical Deep Learning

Engineering practices required to train, debug, reproduce, optimize, and serve neural networks reliably.

## Learning units

- PyTorch fundamentals
- TensorFlow/Keras fundamentals
- tensors and autograd
- modules, datasets, and dataloaders
- writing training loops
- GPU and accelerator fundamentals
- mixed precision
- gradient accumulation
- checkpointing and reproducibility
- experiment tracking
- profiling and bottleneck analysis
- debugging NaNs, gradients, activations, and data pipelines
- transfer learning
- fine-tuning
- parameter-efficient fine-tuning fundamentals
- distributed training concepts
- inference optimization
- model export and serving

The emphasis is on understanding what frameworks automate rather than treating frameworks as black boxes.
